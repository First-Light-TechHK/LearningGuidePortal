## 2. Business Function 与依赖顺序

```text
Course Management
  -> Portal / Public First Lesson
```

Study Group (PRD v0.10): `modules/group-study`, `app/api/study-groups`, `app/api/livekit/webhook`, `app/[locale]/portal/study-groups`, `components/portal/StudyGroupsApp.tsx`. A signed-in learner with Course access creates a public Group and becomes Host. Join is immediate. Each Live Session holds at most 6 people including the Host; a full session refuses another entry, including the Host. Chat stays in LiveKit and is not stored. Each token issuance appends one encrypted log line and no token row. One meeting row is written when the Host starts the Session. AI Tutor queues the participant's own text, retrieves existing Course Knowledge, and publishes one shared LiveKit answer. Enqueue itself does not call a model. A provider-signed LiveKit webhook records a unique receipt, closes an open presence on `participant_left`, and never grants membership or authorization; it requires the PostgreSQL store (see `docs/phase1/study-group/production-persistence-slice2-design.md`). See `docs/phase1/study-group/decisions.md`.

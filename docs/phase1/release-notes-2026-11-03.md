## 问题描述

原反馈：同时学习超过两节课时，“我的学习”只显示一节课；课程菜单无法访问早期课时，第二节课有时消失。

分析确认了两个代码问题：学习页目录会隐藏不支持当前文字/视频模式的课时；My Learning 的缓存刷新仅比较课程和模式，未比较课时、知识点、进度与更新时间。尚未获得原反馈的具体课程和账号，因此不能认定已在目标环境复现并解决全部症状。

My Learning 的既有规则仍为每门 Course 一张卡片，显示当前 Lesson；同一 Course 学习多个 Lesson 不会生成多张课程卡片。

## 修复内容

1. **完整课时目录**：文字/视频模式切换后保留全部目录项；点击课时时选择目标课时支持的模式。没有可用内容的课时保留为禁用项，提供中英文不可用提示；原有试看、订阅和权限限制继续有效。
2. **明确的课时跳转**：跨模式进入课时前保存模式。保存失败时保留当前页面并允许重试；保存成功后进入用户明确点击的课时，不被该模式的历史恢复位置替代。
3. **My Learning 状态同步**：进入页面、恢复浏览器历史、重新聚焦标签页时，比较课程、模式、当前课时、当前知识点、进度和更新时间，按差异刷新卡片和继续学习目标。
4. **学习记录保留**：继续按 Course 汇总卡片，保留学习事件和最高进度；回看早期课时不降低已保存的最高进度。
5. **后续更新规则**：相关测试和必要检查通过后再提交、推送；更新对应的 `fix/*` 或 `feature/*` 分支时同步到 `dev`，保留远端历史，不强制覆盖。

## SIT 验收步骤

1. 确认服务已运行本次发布 SHA，以有有效课程权限的账号登录。
2. 在至少三课的课程中按 Lesson 1 → 2 → 3 → 1 → 2 阅读或实际播放；所有目录项始终存在，早期课时可重新进入。
3. 切换文字/视频模式，分别进入仅文字、仅视频及混合课时；跳转目标、内容和模式应一致。空内容课时保留禁用提示，无权限课时不可进入受保护内容。
4. 在 My Learning 检查同一 Course 仅一张卡片；继续学习进入最新保存的定位，回看不降低最高进度。
5. 标签页 A 停留 My Learning，标签页 B 在相同模式下学习其他 Lesson/知识点；返回 A 或通过浏览器后退恢复时，卡片应更新定位和进度。
6. 交替学习三门 Course，确认各课程卡片和学习历史均保留，互不覆盖。
7. 在测试工具中模拟模式保存失败，确认页面不跳转、有错误反馈且可重试；用英文界面重复关键步骤。
